# Mandate — working agreement for coding agents

Read this first, every session. Then read [docs/PRD.md](docs/PRD.md) (the spec), [docs/plan.md](docs/plan.md) (what is done and what is next) and [docs/decisions.md](docs/decisions.md) (rulings that refine the PRD).

## The rules that matter most

1. **The PRD is the source of truth.** Work milestone by milestone (PRD section 4). Don't start a milestone before the previous one's exit criteria pass. Anything not in the PRD goes in `docs/ideas.md`, not in the code.
2. **Never guess an address, ABI, endpoint or parameter.** Read the deployed contract, the published ABI or the docs, and record what you found in `docs/spikes.md`. Every address in this repo was verified on-chain; keep it that way.
3. **Never claim something works until you have run it.** Paste the command and its output. "The tests pass" means you ran them in this session. If you did not verify it, say so.
4. **Contracts are test-first.** Every function gets Foundry unit tests; every invariant in PRD 7.8 gets an invariant test. `forge test` must be green before you commit contracts.
5. **Never commit secrets.** Keys live in `.env` (gitignored). Before any push, run `git log -p --all | grep -cE '(nsn_|zk_|QN_)[0-9a-f]{20,}|sk-ant-api[0-9]{2}-'` and expect `0`.
6. **Monad specifics:** all time windows count blocks, never timestamps; gas is charged on the limit, so every transaction sets a tight explicit `gas`; full nodes serve no historical state (that is what the indexer is for); block time is measured at runtime (~0.30 s), never hardcoded.
7. **Be honest in the product.** Sample data says "sample data". Scripted demos say they are scripted. Local-fork shims refuse to run against a real network. The README discloses all three.
8. **Small commits**, clear messages, end with the `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` line. The judges must see work done after Sep 1, 2026.

## Checks before you say a milestone is done

```bash
cd contracts && forge test                                   # unit + invariants
cd contracts && FOUNDRY_PROFILE=fork forge test -vv           # real Perpl on a mainnet fork (needs MONAD_RPC_URL)
pnpm -r typecheck && pnpm --filter @mandate/common test && pnpm --filter underwriter test
pnpm --filter app build
```

## Layout

- `contracts/` — Foundry. `MandateRegistry`, `MandateAccount` (+factory), `rules/` (one library per rule), `venues/PerplAdapter.sol`.
- `services/common` — ABIs (generated by `node services/common/scripts/gen-abi.mjs`), network config, Perpl encoding, rule copy.
- `services/underwriter` — Nansen client, scoring, report hashing.
- `services/agent` — the runtime, its providers (Claude, Kimi, scripted demo), setup scripts, the fork-only price sync.
- `app/` — Next.js PWA: Create mandate, agent split screen.
- `docs/` — PRD, plan, spikes, decisions, benchmarks, security.

## Things that will bite you

- Perpl keys accounts by `msg.sender`, so `MandateAccount` trades in its own name. Its `allowOrderForwarding` must never be callable by a session key, or orders could bypass every rule.
- Perpl uses isolated margin: leverage is per order, each position holds its own deposit. Account equity is idle AUSD + venue balance + per-position deposits and unrealized PnL.
- Market ids differ per network (BTC is 1 on mainnet, 16 on testnet), and so do price/lot decimals. Always go through `services/common/src/networks.ts`.
- Nansen matches EVM token addresses in **lowercase** only, and the free plan runs out of credits quickly. The agent reads the stored underwriting report instead of calling Nansen every loop.
- An anvil fork freezes Perpl's oracle, so orders stop filling after 60 s. `pnpm --filter agent fork:sync` mirrors live marks onto the fork. It refuses to run anywhere but localhost.
